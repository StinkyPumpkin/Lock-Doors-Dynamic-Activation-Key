# Lock Doors (Dynamic Activation Key)

Lock and unlock any door in Skyrim yourself. Look at a closed door, press your
activation hotkey, and it's locked — nobody opens it until you unlock it the same
way. Your locked doors stay locked across save and reload.

## Features

- Lock or unlock any door with a single hotkey
- Locked doors block the player and NPCs from opening them
- Toggle: press again on a locked door to unlock it
- Locks persist through saving and reloading
- On-screen prompts (Locked / Unlocked / "Close the door first")

## Requirements

- SKSE64
- PapyrusUtil
- [Dynamic Activation Key](https://www.nexusmods.com/skyrimspecialedition/mods/128694) (provides the activation hotkey)

## Installation

Grab the archive from [Releases](../../releases/latest), install it with your mod
manager (MO2 / Vortex), and enable the plugin. No configuration needed.
